A Wayland-native screen OCR and translation tool for Hyprland. Select a region of your screen, OCR it, and display the result in a persistent popup with translation and romanisation support.

<!-- end-abstract -->

OCRPeeker lets you grab any text on screen — manga panels, subtitles, error dialogs, foreign-language UI — and get an instant OCR + translation popup without leaving what you're doing.

Full installation instructions, configuration, and plugin development docs live in the [GitHub repository](https://github.com/carlesmatoses/OCRPeeker).
